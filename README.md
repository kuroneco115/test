# test — DARK SCHOOL UPDATE 03

スマートフォン・PCのブラウザで遊べる、オリジナル2D見下ろし型ホラーゲームです。

## GitHub Pagesへの反映
1. ZIPを解凍します。
2. `test` フォルダ内の `index.html` と `README.md` を、GitHubリポジトリの同じ場所にアップロードして置き換えます。
3. GitHubの **Settings → Pages** を開き、Branchを `main`、Folderを `/ (root)` にして保存します。
4. 公開URLを開き、再読み込みして **NEW GAME** から開始します。

## 操作
- スマホ：画面左の方向ボタン、右側の「走る」「調べる」「ライト」「目的」
- PC：WASD / 矢印で移動、Shiftで走る、Eで調べる、Fでライト、Mで目的表示
