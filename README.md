# test — SCHOOL LIMINAL (Full Edition)

オリジナルの2D見下ろし型・学校探索ホラーゲーム。スマートフォンとPCのブラウザで動作し、GitHub Pagesで公開できます。

## 仕様
- 目標プレイ時間：20〜30分を想定した短編構成
- 4章：普通教室棟、特別教室棟、図書・音楽室、地下旧校舎
- オリジナルの主人公ドット絵と怪異「ノイズ」
- 歩行・走行、追跡AI、ライト、電池、スタミナ
- 記録片・鍵・電源部品の収集、階層移動、脱出条件
- 隠し記録と複数エンディング分岐の土台
- スマホ用タッチ操作、PC用キーボード操作
- Web Audioによる簡易環境音、画面ノイズ、暗闇表現

## 操作
PC: WASD / 矢印で移動、SHIFTで走る、Eで調べる、Fでライト、Mで地図、ESCで一時停止。
スマホ: 画面左下の方向キー、右下のアクションボタン。

## GitHub Pages
1. ZIPを展開
2. `index.html` と `README.md` をリポジトリ直下にアップロード
3. Settings → Pages → Deploy from a branch
4. `main` / `/(root)` を選んで保存

外部ライブラリ、APIキー、サーバーは不要です。
