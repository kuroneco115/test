# test — 高校2Dホラーゲーム v2

スマートフォン・PC対応の見下ろし型2Dホラー試作品です。

## 今回追加したもの
- 1F・2F・3F・地下の4階層を探索
- 教室・ロッカー・机をイメージした校内装飾
- 各階に記録片と鍵を配置する探索目標
- 階段を使った階層移動と出口のロック
- 追跡する怪物、走ると気づかれやすくなる仕組み
- 環境音の低いドローン音と調査時の効果音（ブラウザの音声許可が必要）
- 黒髪・青緑の制服・赤いバッグのオリジナル学生ドットキャラ。歩行時に上下・足をアニメーション

## 操作
- PC：WASD / 矢印キーで移動、SHIFTで走る、Eで調べる
- スマホ：方向パッドで移動、「走る」を押しながら移動、「調べる」で調査

## クリア条件
4階層それぞれで記録片と鍵を回収し、1Fの出口へ戻ります。
※本作はブラウザで動く試作版です。音声は最初のゲーム開始後に有効になります。
