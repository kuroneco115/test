# test — SCHOOL LIMINAL（アップデート版）

スマートフォン・PCのブラウザで動く、オリジナル2D見下ろし型ホラーゲームです。

## GitHub Pagesへの反映
1. ZIPを解凍します。
2. `test` フォルダ内の `index.html` と `README.md` を、GitHubリポジトリの同じ場所にアップロードして置き換えます。
3. GitHubの **Settings → Pages** を開き、Branchを `main`、Folderを `/ (root)` にして保存します。
4. 公開URLを開き、ブラウザを再読み込みします。

## 操作
- スマホ：画面左の大きな方向キー、右側の「走る」「調べる」「ライト」「地図」
- PC：WASD / 矢印で移動、Shiftで走る、Eで調べる、Fでライト、Mで地図、Escで一時停止
