# test — SCHOOL LIMINAL (Ultimate Prototype)

スマートフォン・PCのブラウザで遊べる、オリジナル2D見下ろし型ホラーゲームです。

## 内容
- 4階層：普通教室棟 / 特別教室棟 / 図書・音楽室 / 地下旧校舎
- ドット絵の主人公（黒髪・青緑の制服・赤いバッグ）と歩行アニメーション
- オリジナル怪異「ノイズ」の徘徊・音への反応・追跡
- 記録片、鍵、電源部品の収集と脱出条件
- 各階の階段、施錠扉、探索用のローカルマップ
- ライト、バッテリー、スタミナ、走行音
- 暗闇、ビネット、ノイズ干渉、環境音と効果音
- 一時停止、ローカルセーブ / コンティニュー
- PCとスマホ両対応

## 操作
### PC
- WASD / 矢印キー：移動
- SHIFT：走る（音が大きくなる）
- E：調べる / アイテム回収 / 階段・出口を使う
- F：ライト ON / OFF
- M：マップ表示
- ESC：一時停止

### スマートフォン
画面左下の方向パッドで移動。右下の「走る」「調べる」「ライト」「マップ」を使用します。

## クリア条件
4つの階層すべてで「記録片」「鍵」「電源部品」を回収し、出口装置を調べます。
各階の階段は同じ位置にあり、Eで次の階層へ移動します。

## GitHub Pagesで公開
1. ZIPを展開します。
2. `index.html` と `README.md` をGitHubリポジトリ直下へアップロードします。
3. `Settings` → `Pages` → `Deploy from a branch` を選びます。
4. Branchを `main`、Folderを `/ (root)` にして保存します。

追加ライブラリやAPIキーは不要です。ブラウザのLocal Storageに進行状況を保存します。
