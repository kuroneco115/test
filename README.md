# test - 高校ホラーゲーム

スマートフォン・PCのブラウザで遊べる、見下ろし型2Dホラーゲームです。

## 遊び方
- `index.html` をブラウザで開くと遊べます。
- GitHub Pagesで公開する場合は、このフォルダ内の `index.html` をリポジトリの直下にアップロードし、Settings → Pages から公開設定を行ってください。
- PC：WASD / 矢印キーで移動、SHIFTで走る、Eで出口を調べる
- スマホ：画面左下の方向パッドで移動、右下の「調べる」で出口を操作

## 目的
校内にある3つの記録片を集めて、最下部右側のEXITから脱出します。
暗闇の中を徘徊する存在に接触するとゲームオーバーです。
